# 📚 مكتبة تحليل المستندات

موجهات تحليل العقود والتقارير — نفس الموجهات المدمجة في شرائط الواجهة، بصيغة قابلة للتعديل.

**العلاقة بالواجهة:** الواجهة تحمل نسخة مدمجة من هذه الموجهات؛ هذا المجلد نسخة الإنسان: حرّرها وجرّب صياغاتك الخاصة، ثم الصق النص المعدل في مربع الحوار مباشرة.

**نصيحة عامة:** أفضل الموجهات تحدد (الدور + السياق + المهمة + صيغة المخرجات). أضف دائماً ما يخص حالتك للسطر الأول قبل الإرسال.
