# 🍃 المساعد الشامل المتنقل — Eco-AI Portable Kit

> **ذكاء اصطناعي خفيف وسريع على أي جهاز — حتى بدون كرت شاشة وبذاكرة 4GB فقط، مع حفاظ ممتاز على البطارية.**
> منتج محمول يعمل من وحدة التخزين (USB / SSD خارجي) بشكل كامل **دون إنترنت** — بنقرة واحدة، ودون أي تثبيت على الجهاز المضيف.

---

## 🎯 لمن هذا المنتج؟
أصحاب الأجهزة القديمة أو الضعيفة (بدون كرت شاشة) · الطلاب · الاستخدام اليومي الخفيف: بريد، تلخيص، ترجمة، أفكار · من يحتاج بطارية تدوم طويلاً.

## 📦 ماذا يتضمن؟

| المكوّن | الوصف |
|---|---|
| محرك الاستدلال | `llama.cpp (llama-server)` — مفتوح المصدر، محمول بالكامل |
| النموذج | نموذج لغة بصيغة GGUF من اختيارك (انظر `models/DOWNLOAD-LIST.md`) |
| الواجهة | واجهة ويب عربية RTL تعمل من الملف مباشرة (`ui/index.html`) |
| سكربتات التشغيل | `START` و `STOP` و `SETUP` لـ Windows و macOS/Linux |
| مكتبة الموجهات | اختصارات المهام اليومية الجاهزة في `prompts/` |
| التوثيق | دليل مستخدم + توثيق تقني للمطور |

## 🖥️ المتطلبات

| النموذج المقترح | الحجم | RAM مطلوبة | ملاحظات |

| Llama-3.2-3B-Instruct — الموصى به | 1.9 GB | 4GB RAM | الخيار الأساسي: سريع ودقيق لأجهزة 4-8GB بدون كرت شاشة |
| Qwen2.5-3B-Instruct — عربي أقوى | 2.0 GB | 4GB RAM | أفضل قليلاً في العربية والصينية — خيار ممتاز للمحتوى العربي |

- **نظام التشغيل:** Windows 10/11 (x64) · macOS 12+ · Linux x64/arm64
- **المساحة على الفلاشة:** حجم النموذج + ‏50MB
- **لا يحتاج:** تثبيت برامج، حسابات، أو إنترنت بعد الإعداد الأولي

## ⚡ الإعداد لمرة واحدة (يتطلب إنترنت)

> الفكرة: تجهّز الفلاشة مرة واحدة على جهاز متصل بالإنترنت، ثم تستخدمها بعد ذلك على أي جهاز **بدون أي اتصال**.

### على Windows
1. أدخل وحدة التخزين وافتح مجلد هذا المنتج.
2. انقر نقراً مزدوجاً على **`SETUP-Windows.bat`**.
3. اختر نوع المحرك (1 = المعالج الأكثر توافقاً، 2 = Vulkan للتسريع بأي كرت شاشة، 3 = CUDA لكرت NVIDIA).
4. اختر النموذج المناسب لمواصفات جهازك من القائمة.
5. انتظر انتهاء التنزيل — انتهى الإعداد نهائياً.

### على macOS / Linux
```bash
cd /Volumes/YOUR_USB/04-Eco-AI-Kit     # أو مسار الفلاشة
bash SETUP-Mac-Linux.sh
```
- على macOS: اختر Homebrew (الأسرع) أو البناء من المصدر (الأكثر قابلية للنقل بين الأجهزة).
- على Linux: يُبنى المحرك من المصدر تلقائياً (يتطلب git وcmake ومترجم C++).

## 🚀 التشغيل اليومي (دون إنترنت)

1. وصّل وحدة التخزين بأي جهاز.
2. **Windows:** انقر نقراً مزدوجاً على **`START-Windows.bat`**
   **macOS/Linux:** نفّذ `bash START-Mac-Linux.sh`
3. انتظر رسالة جاهزية المحرك (النماذج الكبيرة تحتاج 1–5 دقائق أول مرة).
4. ستفتح الواجهة في المتصفح تلقائياً — ابدأ العمل.
5. عند الانتهاء شغّل `STOP-Windows.bat` / `bash STOP-Mac-Linux.sh` لإيقاف المحرك.

> 💡 يمكن إغلاق نافذة السكربت بعد التشغيل — المحرك يعمل في نافذة مصغّرة مستقلة.

## 🔒 أين تُحفظ بياناتي؟

| النوع | المكان | هل يخرج من الجهاز؟ |
|---|---|---|
| المحادثات | ذاكرة المتصفح المحلية (localStorage) على الجهاز المضيف | لا |
| المستندات التي ترفقها | تُقرأ في المتصفح فقط ولا تُنسخ لأي مكان | لا |
| سجلات المحرك | `logs/engine.log` على الفلاشة | لا |
| النموذج والإعدادات | الفلاشة نفسها | لا |

المحرك يستمع على `127.0.0.1` فقط (loopback) — أي لا يمكن لأي جهاز آخر على الشبكة الوصول إليه أصلاً. راجع `../SECURITY.md` لقائمة الفحص الكاملة.

## 🔄 استبدال النموذج أو ترقيته

1. حمّل أي ملف `.gguf` جديد (من Hugging Face مثلاً) على جهاز متصل.
2. انسخه إلى مجلد `models/` هنا.
3. حدّث `MODEL_FILE` في `config/settings.conf` باسم الملف، أو اتركه `AUTO` ليُختار الأكبر تلقائياً.
4. أعد تشغيل `START`. التفاصيل الكاملة في `docs/TECHNICAL.md`.

## 🛠️ استكشاف الأخطاء

| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| «NO MODEL FILE FOUND» | مجلد models فارغ | شغّل SETUP أو انسخ ملف .gguf يدوياً |
| «ENGINE NOT FOUND» | SETUP لم يكتمل | شغّل SETUP-Windows.bat أولاً |
| يعلّق في «Loading model» طويلاً | النموذج أكبر من RAM | اختر نموذجاً أصغر من DOWNLOAD-LIST.md |
| انهيار المحرك فور الإقلاع | ملف نموذج تالف / ناقص | أعد تشغيل SETUP لاستكمال التنزيل (يدعم الاستئناف ويتحقق من الحجم) |
| `CORS allows all origins` في السجل | إشعار معلوماتي متوقع | لا شيء — هو ما يتيح لواجهة المنتج المحلية الاتصال بالمحرك |
| الواجهة تقول «غير متصل» | المحرك لم يجهز بعد أو المنفذ مأخذ أو لقطة نافذة المتصفح من جلسة سابقة | انتظر، أو أغلق تبويب الواجهة القديم وافتح `ui/index.html` من جديد |
| بطء شديد في الردود | يعمل على المعالج بنموذج كبير | شغّل SETUP واختر بنية Vulkan/CUDA، أو نموذجاً أصغر |
| «المنفذ مستخدم» | تطبيق آخر يستخدم 8804 | غيّر `PORT` في config/settings.conf ثم أعد START |
| ماك يرفض تشغيل السكربت | صلاحيات التنفيذ على أنظمة exFAT | نفّذه بـ `bash START-Mac-Linux.sh` |
| ويندوز يحذّر من السكربت | SmartScreen للملفات المنزّلة | More info ← Run anyway (الملفات المنسوخة لفلاشة عادة لا تُحذَّر) |

الأسئلة الشائعة وسيناريوهات الاستخدام التفصيلية في **`docs/USER-GUIDE-AR.md`**.
