# 🐞 تشخيص خطأ منهجي

**التصنيف:** المراجعة والتشخيص  
**الوصف:** من رسالة الخطأ إلى الإصلاح الجذري  
**درجة حرارة مقترحة:** 0.2

## القالب

```text
ساعدني في تصحيح هذا الخطأ بمنهجية.

اللغة/التقنية: {LANGUAGE}

رسالة الخطأ الكاملة:
```

```

الكود المشتبه به:
```

```

ما جربته حتى الآن:
-

المطلوب: (1) تفسير رسالة الخطأ بدقة (2) أهم سببين محتملين مرتبين (3) خطوة تحقق سريعة لكل سبب (4) الإصلاح المقترح كاملاً (5) كيف أتأكد أن الإصلاح نهائي وليس ترقيعاً.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
