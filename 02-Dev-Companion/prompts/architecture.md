# 🏗️ تصميم معماري

**التصنيف:** الهندسة  
**الوصف:** حل معماري مع موازنة البدائل  
**درجة حرارة مقترحة:** 0.4

## القالب

```text
اقترح معمارية للحاجة التالية:

السياق والمتطلبات:

القيود (أداء/تكلفة/فريق):
- 

أنتج: (1) نمط معماري مقترح مع مبررات (2) رسم ASCII للمكونات وتدفق البيانات (3) جدول موازنة لبديلين آخرين (4) أكبر 3 مخاطر تقنية وتخفيفها (5) خطة مرحلية للتنفيذ.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
