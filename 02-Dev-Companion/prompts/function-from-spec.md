# ⚙️ دالة من مواصفة

**التصنيف:** التوليد  
**الوصف:** دالة موثقة بحدودها وحالاتها  
**درجة حرارة مقترحة:** 0.2

## القالب

```text
اكتب دالة وفق المواصفة:

اللغة: {LANGUAGE}
الاسم المقترح:
المدخلات (نوع ومعنى):
- 
المخرجات:
- 
الحالات الحدية:
- 

اكتب: توقيعاً واضحاً، توثيقاً كاملاً (docstring)، تنفيذاً نظيفاً، ومعالجة صريحة للحالات الحدية، ثم 4 أمثلة استخدام.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
