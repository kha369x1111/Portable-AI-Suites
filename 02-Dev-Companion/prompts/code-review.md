# 🔎 مراجعة كود احترافية

**التصنيف:** المراجعة والتشخيص  
**الوصف:** فحص شامل: منطق، أمان، أداء، قراءة  
**درجة حرارة مقترحة:** 0.2

## القالب

```text
راجع الكود التالي كما يفعل مهندس أول في فريق كبير:

اللغة/التقنية: {LANGUAGE}

```

```

غطِّ بالترتيب: (1) الصحة والمنطق (2) الأمان (3) الأداء (4) القراءة والتسمية (5) معالجة الأخطاء (6) الحالات الحدية.
صنّف كل ملاحظة: 🔴 يجب إصلاحه · 🟡 يُنصح · 🟢 رأي شخصي.
اختم بنسخة محسّنة كاملة مع قائمة بأهم 3 تحسينات.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
