# 🗄️ SQL من متطلبات

**التصنيف:** التوليد  
**الوصف:** مخطط + استعلام + فهارس  
**درجة حرارة مقترحة:** 0.2

## القالب

```text
حوّل المتطلبات التالية إلى SQL:

قاعدة البيانات: {LANGUAGE}

المتطلبات:

المطلوب: (1) مخطط الجداول مع الأعمدة والأنواع والعلاقات (2) الاستعلام الأساسي المطلوب (3) فهارس مقترحة مع سبب كل فهرس (4) استعلامات تشغيل شائعة قد أحتاجها (5) ملاحظات أداء.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
