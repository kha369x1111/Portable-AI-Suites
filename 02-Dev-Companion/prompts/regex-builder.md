# 🔤 بناء Regex

**التصنيف:** التوليد  
**الوصف:** نمط + شرح + اختبارات  
**درجة حرارة مقترحة:** 0.2

## القالب

```text
ابنِ لي تعبيراً نمطياً (Regex) لهذا الغرض:

اللغة: {LANGUAGE}

ما يجب أن يطابق:
- 
ما يجب ألا يطابق:
- 

أعطني: النمط النهائي، شرحاً جزءاً جزءاً، و10 حالات اختبار (مطابق/غير مطابق) في جدول.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
