# 🔄 تحويل/ترحيل كود

**التصنيف:** التوليد  
**الوصف:** بين اللغات أو الأطر أو الإصدارات  
**درجة حرارة مقترحة:** 0.3

## القالب

```text
حوّل الكود التالي:

من: 
إلى: {LANGUAGE}

```

```

حافظ على السلوك تماماً. اذكر: (1) الفروقات الجوهرية بين البيئتين (2) الكود المحوّل كاملاً (3) مكتبات {LANGUAGE} المقابلة المستخدمة (4) ما يجب اختباره بعد الترحيل.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
