# 🔌 تصميم API

**التصنيف:** الهندسة  
**الوصف:** نقاط نهاية REST موثقة  
**درجة حرارة مقترحة:** 0.3

## القالب

```text
صمّم API للمجال التالي:

السياق:

المتطلبات:
- 

أنتج: (1) قائمة نقاط النهاية (الطريقة، المسار، الوصف) في جدول (2) نماذج الطلب/الاستجابة (3) رموز الحالة ومعالجة الأخطاء (4) قواعد المصادقة (5) مثالاً لكل نقطة رئيسة.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
