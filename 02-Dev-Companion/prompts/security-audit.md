# 🛡️ تدقيق أمني

**التصنيف:** المراجعة والتشخيص  
**الوصف:** OWASP-style للكود المعطى  
**درجة حرارة مقترحة:** 0.2

## القالب

```text
قم بتدقيق أمني للكود التالي:

```

```

افحص: الحقن (SQL/Command/XSS)، إدارة الأسرار والمفاتيح، التحقق من المدخلات، مصادقة/تفويض، معالجة الأخطاء المكشوفة، اعتمادات قديمة.
لكل ثغرة محتملة: الخطورة (حرجة/عالية/متوسطة/منخفضة)، السيناريو، والإصلاح مع كود بديل.
```

## طريقة الاستخدام

1. افتح الواجهة ← «مكتبة القوالب» 🧰 ← انقر القالب (يُدرج تلقائياً)، أو انسخ القالب أعلاه.
2. استبدل `{LANGUAGE}` باسم لغتك وتقنيتك.
3. الصق الكود/التفاصيل مكان الأقواس الفارغة.
4. أرسل، وتابع الحوار خطوة بخطوة.
